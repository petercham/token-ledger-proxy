# legacy/ · 旧读日志方案的可选兼容件

这两个文件来自 5090 工具包里的 `skill-token-ledger`，**主链完全不依赖它们**。

| 文件 | 用途 |
|---|---|
| `collector_log.py` | 从引擎日志文本里解析 token 用量，写成同格式的 `requests-YYYY-MM-DD.jsonl` |
| `scheduler.py` | 独立的每日定时排程（本工具已把日报并进服务进程，一般用不到） |

什么时候才用：目标机上确实还想保留「读日志」那条旁路链（例如引擎完全不开 key、又不想让任何东西挡在业务前面）。它们需要自己的配置和日志指针文件，与本包的 `config.json` 不通用。

**注意**：读日志那条链在并行批处理时数字会失真（5090 说明里自报约 3.9%），而且算不到具体的人。本包的主链没有这两个问题。

新旧 `requests-*.jsonl` 的核心字段一致，可以放进同一个 `out_dir` 一起出日报，见根目录 `README.md` 第四节。
